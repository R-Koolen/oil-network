Click a country in the graph, or choose one from the list, to see its numbers.

  • The three columns are not on one scale: production and consumption are in thousand barrels per day (kb/d), refining throughput is in thousand tonnes per year (kt/yr). Node height is proportional to value on a fixed scale for each column, the same in every year, so the same height means the same value whichever year you pick. Values too small for that scale are drawn at a minimum height.
  • Line width is trade value in US dollars, one scale for both crude and product flows and for every year. Trade values are nominal US dollars, so oil prices move them a lot. Tonnes are not used: some tonnage figures in the trade data are unreliable.
  • Flows inside a country (for example, a country refining its own crude) are not in the data and are not drawn.
  • A country marked “no data” appears because a drawn flow starts or ends there, but the source has no number for it in that column.
  • Hover over a node or a line for its values.
